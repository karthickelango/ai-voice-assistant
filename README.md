# Karthick AI / Thruv - Frontend Application

Modern React 19 + Tailwind CSS + Vite frontend for Karthick AI / Thruv.

## 🚀 Running Locally

### 1. Navigate to the frontend folder
```bash
cd frontend
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Ensure Backend is Running
Make sure the backend is running in another terminal window on `http://localhost:5000` (see `../backend/README.md`).

### 4. Start Development Server
```bash
npm run dev
```

The frontend will open on `http://localhost:5173`.
All requests to `/api` are automatically proxied by Vite to the backend on `http://localhost:5000`.
